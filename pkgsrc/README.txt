Panel Attack for Miyoo Mini Plus (OnionOS)
https://github.com/snyderman3000/panelattack-miyoo

Install: copy the App folder to the root of the SD card (or install it with
Mixtape). Launch "Panel Attack" from Apps.

Controls
  D-pad          move cursor / menus
  A, B           swap panels / select, back
  L1/L2, R1/R2   raise the stack
  X, Y           taunts
  Start          pause / ready
  Select         back
  Select+Start   quit

Online play connects to the official Panel Attack server (panelattack.com)
over Wi-Fi. The first time, set a name with the on-screen keyboard
(D-pad move, A type, B delete, X case, START done).

Sound is not supported yet.
Saves and settings live in PanelAttack/data. The log of the last run is
PanelAttack/log.txt; please attach it to bug reports.
